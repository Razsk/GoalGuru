# Asymmetric Subgraph Detail Pruning

Exported subgraph contexts include full detail for the focused node, but condense ancestors to high-level objectives, prune descendant descriptions beyond depth 1, and reduce dependencies to status metadata.

LLM reasoning degrades when flooded with irrelevant sibling or ancestor details. Asymmetric pruning preserves the necessary causal narrative while keeping context token usage minimal and focus tight.
